## Project Description

This assignment implements an interactive R Shiny portfolio dashboard that fetches historical stock data from Yahoo Finance. The dashboard supports Daily, Weekly, and Monthly time frames, Line/Candlestick/Area chart types, Moving Average overlays, RSI and MACD indicator panels, and a customizable moving-average crossover strategy that generates Buy, Sell, and Hold signals with chart annotations.
